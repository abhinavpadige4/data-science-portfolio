# Free Static-Site Hosting Options for 2026

## Introduction
This document provides a comparison of three popular free static-site hosting services: GitHub Pages, Netlify, and Vercel. The comparison includes a feature matrix and a recommendation based on various criteria such as ease of use, performance, and additional features.

## Feature Matrix
### GitHub Pages
- **Pros:**
  - Integrated with GitHub repositories.
  - Simple setup and deployment.
  - Included SSL certificates.
- **Cons:**
  - Limited custom domain options.
  - No build automation or CI/CD integration.
  - No previews or drafts.
  - Basic analytics and SEO features.

### Netlify
- **Pros:**
  - Easy integration with Git repositories.
  - Automatic builds and deployments.
  - Full support for custom domains.
  - Included SSL certificates.
  - Previews and drafts for pull requests.
  - Basic analytics and SEO features.
- **Cons:**
  - Bandwidth limitations in the free tier.
  - Limited number of sites per account.

### Vercel
- **Pros:**
  - Seamless integration with Git repositories.
  - Automatic builds and deployments.
  - Full support for custom domains.
  - Included SSL certificates.
  - Previews and drafts for pull requests.
  - Advanced analytics and SEO features.
- **Cons:**
  - Bandwidth limitations in the free tier.
  - Limited number of sites per account.

## Recommendation
For a data-science student looking to host a single-page portfolio site, **Vercel** is the recommended option due to its excellent speed performance, advanced SEO features, and seamless integration with Git repositories. While both GitHub Pages and Netlify offer solid free tiers, Vercel's superior performance and additional features make it the best choice for showcasing a professional portfolio.

## Conclusion
Each of these platforms has its strengths and weaknesses. The decision should be based on specific needs such as the complexity of the site, required features, and future scalability. For a simple yet professional portfolio, Vercel stands out as the top choice.
