# Data Science Student Portfolio

This repository contains a single-page portfolio website built for a data science student using plain HTML, CSS, and Tailwind CSS via CDN. The site is designed to showcase the student's skills, projects, education, and contact information.

## Features
- **Semantic HTML**: Structured content with meaningful tags.
- **Responsive Design**: Adapts to different screen sizes.
- **Interactivity**: Smooth scrolling, mobile menu toggle, and form validation.
- **Tailwind CSS**: Utilizes Tailwind CDN for rapid styling.

## Setup Instructions
1. **Clone the Repository**:
   ```bash
   git clone https://github.com/yourusername/data-science-portfolio.git
   cd data-science-portfolio
   ```
2. **Open the Project**:
   Open `index.html` in your preferred web browser to view the portfolio.

## Usage
- **Hero Section**: Introduces the data science student with a brief overview.
- **About Section**: Provides more detailed information about the student.
- **Skills Section**: Lists the technical skills and tools the student is proficient in.
- **Projects Section**: Displays screenshots and descriptions of key projects.
- **Education Section**: Outlines the educational background of the student.
- **Contact Section**: Includes a form for visitors to get in touch.

## Deployment
The portfolio can be deployed to Vercel by following these steps:
1. **Create a Vercel Account**: Sign up at [Vercel](https://vercel.com).
2. **Import the Repository**: Connect your GitHub account and import the repository.
3. **Deploy**: Vercel will automatically detect the static site and deploy it.

## File Structure
- `index.html`: Main HTML file containing semantic sections.
- `css/style.css`: Base CSS file for styling.
- `css/responsive.css`: CSS file for responsive design.
- `js/main.js`: JavaScript file for interactivity.
- `assets/profile.jpg`: Profile picture of the data science student.
- `assets/project1.png`, `assets/project2.png`, `assets/project3.png`: Screenshots of projects.
- `README.md`: This documentation file.
- `hosting_research.md`: Research on top 3 free static-site hosting options.
